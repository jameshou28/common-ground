# v2.1 and v2.1.1 changes

Two quick rounds on top of v2.0.1, both on the v1 profile (about 31 min each). The terrain model itself (tokens, pair model, weighting, region accuracy 0.49, planet check 0.65 / 0.68) didn't change in either. These rounds change how the scores are put together, the landforms, and speed. What ships is **v2.1.1** (`regions-2.1.1-v1`).

## v2.1: tried

| Change | Expected | What happened |
| --- | --- | --- |
| Aridity input for the surface model (Global Aridity Index v3.1, Zomer et al. 2022, CC BY 4.0) | Bare semi-arid land stops getting a free 100; hyper-arid rock scores best | Held-out surface rank got a bit worse (29.7% vs 28%). And it backfired on cold deserts: aridity is rain over evaporation, evaporation is tiny in the Arctic, so Haughton's surface fell 96 -> 77 and Holuhraun's 93 -> 78. **Dropped in v2.1.1.** |
| overall = terrain x (surface/100)^0.5 | Surface only trims the score, no more inflation | Worked as designed, but overall then always sat below both numbers (terrain 57, surface 89 -> 53), which reads wrong. **Replaced in v2.1.1.** |
| Terrain lift, similarity = 100 x p^0.55 | Mid-range matches up, order unchanged | Meteor terrain 60 -> 74, Holuhraun 66 -> 79, but the Amazon too (13 -> 28). Only made sense next to the discount. **Not used in v2.1.1** (the search turned it down, see below). |
| Landform validation over every tagged block | Most landforms couldn't be tested (too few held-out blocks) | 11 -> **19 of 34 validated**. Kept. |
| Landform shortlist 30 -> 15 | Faster clicks | Scoring 0.75 s -> about 0.55 s. Kept. |
| Parallel reads (both elevation windows, land cover, tiles) | Faster clicks | Reads 2.4 s -> 0.8 s, identical results. End to end on a local API, 3.2 s -> 1.7 s. Kept. |

## v2.1.1: ships

- **overall = terrain^0.65 x surface^0.35**, a weighted geometric mean. It always sits between the two numbers, and terrain counts about twice as much as surface. (v2.0 was the plain geometric mean, 0.5 / 0.5.)
- Picked from 271 settings on held-out sites, under these rules: the negative set passes, verified sites keep at least 92% of v2.0's median overall, random land is no higher than v2.0, then the best analog rank. Only one setting of this kind met all of them: surface weight 0.35, no terrain lift, floor 0.2.
- No aridity in the surface model. The grid is still in `model.npz` and the readers still return it, so it's ready if we find a temperature-aware version.
- Each landform now carries its own `overall` from the same formula. The site's feature gauge was using the old sqrt formula, which is why the feature showed 77 next to a region of 53.
- Plus everything kept from v2.1: landform validation, the shorter shortlist, parallel reads.

## Is it better?

- **Accuracy: no real change.** The differences in analog rank (20.7-22.0%) are within the noise for 56 sites, and the check-site order is the same in all three (only the Amazon and the Himalaya swap in v2.1.1).
- **Behaviour: better.** Overall is now between terrain and surface, surface can't carry a weak terrain match as far, and the feature gauge is consistent with the region gauge.
- **Landforms: clearly better.** 19 validated instead of 11.
- **Speed: clearly better.**
- **Stability:**
  - Region accuracy is 0.494 ± 0.013 over the bootstrap.
  - The analog-site numbers have an uncertainty of about ±4% on a median rank. Anything under that between versions is noise.
  - The check-site order hasn't moved in three versions.

## What the check sites say is actually wrong: the terrain score

- The Amazon gets terrain 52 because GLO-30 is a surface model: it includes the tree canopy, so a rainforest looks rough. This is the trap the check list was written to catch.
- Haughton (29) and Timanfaya (35) score low on terrain even though they're textbook analogs.
- Changing how surface and terrain are combined only reshuffles these. The next real gain has to come from the terrain side:
  1. **Bare-earth elevation for Earth.** FABDEM removes trees and buildings from Copernicus DEM, which fixes the canopy trap at the source. But its licence is CC BY-NC-SA (non-commercial, share-alike), and it isn't on a public bucket we can read per click. It would need hosting.
  2. **Region competition in training** (a softmax over regions next to the ranking loss), for region accuracy.
  3. **Full profile** (2,000 library blocks per region, 20,000 random land): more library coverage for the weak regions, more landforms validated, steadier Earth percentiles.
