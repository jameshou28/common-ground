# v2.1 changes

`regions-2.1-v1`. The terrain model (tokens, pair model, weighting) wasn't retrained differently; this version changes how the scores are put together, adds aridity, and fixes landform validation. Training run 31 min.

## What changed

- **Aridity input.** Conditions now see the Global Aridity Index v3.1 (Zomer, Xu & Trabucco 2022, figshare 7504448, CC BY 4.0), rain over potential evaporation. It's averaged to the rainfall grid and stored in `model.npz`, so clicks don't read anything extra. Wetter is worse; bare semi-arid land no longer gets the same surface score as hyper-arid rock. Analog sites median AI 0.15, random land 0.67.
- **Overall = landscape x (surface / 100)^beta** instead of sqrt(landscape x surface). Surface only discounts; it can't lift a weak terrain match.
- **Terrain lift.** Similarity = 100 x p^k with k <= 1. It lifts mid-range matches more than the best ones and keeps the order. Breakdowns still add up exactly.
- **Earth factor shape** (floor + (1 - floor) x percentile^gamma) searched too.
- floor, gamma, beta and k are picked together on held-out sites. Rules: the negative set passes, verified sites keep at least 92% of v2.0's median overall, random land scores no higher than in v2.0, then the best analog rank.
- **Landform validation** uses every tagged library block (own group left out), not just the held-out fifth.
- **Landform shortlist** 30 -> 15 blocks (faster clicks).
- **Readers** read both elevation windows, the land cover and the GLO-30 tiles at the same time.

## Results

| | v2.0.1 | v2.1 |
| --- | --- | --- |
| Chosen | floor 0.2, sqrt | floor 0.2, gamma 1, beta 0.5, k 0.55 |
| Verified terrain sites, overall rank (0% = top) | 22.7% | 20.7% |
| Verified sites, median overall | 53.5 | 49.3 |
| Random land, median overall | 34.7 | 30.0 |
| Gap between them | 18.8 | 19.3 |
| Negative set | PASS | PASS |
| Landforms validated | 11 of 34 | 19 of 34 |
| Region accuracy, planet check | 0.49, 0.65 / 0.68 | unchanged |

Example clicks (Moon, best region):

| Place | Terrain v2.0.1 -> v2.1 | Surface | Overall v2.0.1 -> v2.1 |
| --- | --- | --- | --- |
| Meteor Crater (maria) | 60 -> 74 | 89 -> 83 | 73 -> 68 |
| Holuhraun (maria) | 66 -> 79 | 93 -> 78 | 78 -> 70 |
| Amazon (south pole) | 13 -> 28 | 14 -> 14 | 13 -> 10 |

So terrain now carries the score, surface trims it, and ordinary land drops more than the analog sites do.

## Speed

Readers: fetching one click's data went from 2.4 s to 0.8 s (8 places, same results to the bit). End to end through a local API, a new click went from 3.2 s to 1.7 s on average. The API now writes the Supabase cache after responding (backend branch).
